# Rupali Jat | Portfolio

Scroll-driven 3D night drive through a data city. Built with HTML, CSS, JavaScript and Three.js.

## Files
- `index.html` the whole portfolio (styles and scripts included)
- `photo.jpg` your portrait used in the about section
- `favicon.svg` tab icon
- `404.html` page shown for wrong links
- `.nojekyll` tells GitHub Pages to serve the files as they are

## Deploy on GitHub Pages
1. Create a new public repository (name it `rupali140.github.io` for a link with no repo name).
2. Upload every file from this folder to the main folder of the repo.
3. Go to Settings > Pages. Set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. Open `https://rupali140.github.io/<repo-name>/` after 1 to 2 minutes.

## Edit your details
Open `index.html` and search for the text you want to change (email, links, project descriptions, certificates).

## Run locally
Double-click `index.html`. An internet connection is needed for the Three.js library and fonts.
